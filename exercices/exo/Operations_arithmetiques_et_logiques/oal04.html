Décalage

Soit la variable a déjà initialisée dans le code. Chargez cette variable dans R0, puis utilisez des opérations de décalage (LSR et LSL) pour placer les valeurs:

  • 0x00004000 dans R1;
  • 0x00000800 dans R2;
  • 0x00000100 dans R3;
  • 0x00000040 dans R4;
  • 0x00010000 dans R5;
  • 0x00400000 dans R6;
  • 0x00080000 dans R7;
  • 0x01000000 dans R8;
