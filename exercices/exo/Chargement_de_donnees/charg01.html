Déclaration de variables

Déclarez les variables suivantes :

  1. Une variable a de 8 bits dans la section DATA;
  2. Une variable b de 32 bits qui a une valeur de 0x00000004 dans la section CODE;
  3. Une variable tableau de 3 éléments de 32 bits dans la section DATA.
SECTION INTVEC main B main SECTION CODE SECTION DATA 
SECTION INTVEC

main
B main

SECTION CODE
b ASSIGN32 0x00000004

SECTION DATA
a ALLOC8 1
tableau ALLOC32 3
