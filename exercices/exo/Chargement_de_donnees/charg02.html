Écriture en mémoire

Soit la variable a qui alloue 32 bits en mémoire. On veut écrire le nombre 0x02 en mémoire, à l’adresse indiquée par la variable a.

Effectuez cette action en utilisant R0 pour stocker l’adresse de la variable a et R1 pour stocker le nombre 0x02.

SECTION INTVEC B main SECTION CODE main SECTION DATA 
SECTION INTVEC

B main

SECTION CODE

main
LDR R0, =a 
MOV R1, #0x02
STR R1, [R0]

fin
B fin

SECTION DATA
a ALLOC32  1
