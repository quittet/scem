Comparaison de deux nombres

Soient les registres R0 et R1 contenant chacun un nombre quelconque de votre choix. En utilisant les drapeaux, affectez la valeur 1 à R2 si R0 et R1 sont égaux, sinon affectez-lui la valeur 0. Testez votre code en variant les valeurs des registres.

SECTION INTVEC B main SECTION CODE main SECTION DATA 
SECTION INTVEC

B main

SECTION CODE

main
MOV R1, #0x04
MOV R0, #0x05
CMP R1, R0
MOVEQ R2, #0x01
MOVNE R2, #0x00 ; (Cette ligne n’est pas obligatoire puisque R2 est à 0 au depart)

fin
B fin

SECTION DATA
