Soustraction modifiée

Soient les registre R0 et R1. Écrivez un programme qui:

  1. si R1 est négatif, place le résultat de R0 + R1 dans R2;
  2. si R1 est positif, place le résultat de R0 - R1 dans R2;
  3. si R1 est égal à 0, place R0 dans R2.

Pour cet exercice, n'utilisez pas de branchement (l'instruction B).

SECTION INTVEC B main SECTION CODE main SECTION DATA 
SECTION INTVEC

B main

SECTION CODE

main
CMP R1, #0x00
ADDLT R2, R0, R1
SUBGT R2, R0, R1
MOVEQ R2, R0

fin
B fin

SECTION DATA
