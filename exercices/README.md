# Exercices

Déposer ici les fichiers d'exercices d'epater (HTML contenant les `div`
`enonce`, `code` et `solution`). Ce répertoire est monté en lecture seule
dans le conteneur à l'emplacement `/app/epater/exercices` (voir
`docker-compose.yml`). Un fichier `prive.txt` listant les exercices réservés
au mode privé y est aussi lu par epater.
