Accès mémoire avec variable (1)

Petit programme pour analyser la façon dont l'assembleur gère les variables.

SECTION INTVEC B main SECTION CODE ; Allouons une variable (adresse 0x80) maVariable ASSIGN32 0x1 main ; Question: par quoi l'assembleur remplace-t-il cette instruction? ; Indice: regardez dans la case "instruction courante" en haut à droite... LDR R0, maVariable fin B fin SECTION DATA

Solution

Questions et réponses:

  • Par quoi l'assembleur remplace-t-il cette instruction? Selon la case "instruction courante", il la remplace par LDR R0, [R15, -0x0C] , soit un LDR relatif à PC (R15). Pourquoi -0x0C? Car PC contient 0x8C, alors 0x8C - 0xC = 0x80, ce qui est bien l'adresse de maVariable.
